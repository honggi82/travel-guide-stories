# 여행노트 이야기 가이드

출처를 연결한 한국어 이야기 해설과 지역별 오프라인 팩입니다. 현재 25개국·51개 지역·143개 장소를 수록합니다. 이 중 23개 도시는 각각 주요 명소 5곳을 포함합니다. 빈·부다페스트·베네치아·피렌체에 각각 5곳을 추가했습니다. 참고 저장소의 34개 지역 모두에 최소 한 장소가 있으며, 추가 해외 지역 17개가 있습니다. 아테네 아크로폴리스는 누락 장소 요청 흐름을 통해 새로 조사해 추가했습니다. 지역별로 수록 장소 수가 적으므로 방문지를 계획할 때 인덱스의 실제 수록 목록을 확인해 주세요. 세계의 모든 관광지를 수록한 데이터베이스는 아닙니다.

`index.json`의 실제 UTF-8 바이트 크기와 SHA-256으로 다운로드를 검증합니다. 각 장소는 별칭, 도시, 참고 좌표, 해설, 조사일, 출처를 갖습니다. 참고 좌표는 GPS 안내용 위치 확인을 대신하지 않습니다.

## 자료 사용과 출처

한국어 본문은 Codex가 연결된 Wikipedia의 사실을 바탕으로 새로 구성했습니다. Wikipedia 기여자의 원문은 각 `sources` 링크에서 확인할 수 있습니다. 본문은 CC BY-SA 4.0으로 제공합니다. 사실의 선택·재구성과 한국어 이야기 구성에 변경이 있습니다. 원문 인용, Google 리뷰·사진의 복제는 포함하지 않습니다.

Google 지도 검색 링크를 장소마다 제공합니다. 색인된 지도 페이지에서 이름·도시와 표시된 경우 주소를 확인한 장소는 `mapsVerification: indexed-identity`와 출처 링크로 기록했습니다. 기자 피라미드군은 Giza Necropolis의 이름·주소를 확인했고, 런던탑은 런던 관광 명소 검색 목록에서 이름·도시만 확인했습니다. 지도 본문을 확인하지 못한 장소는 `pending`입니다. 이 식별 확인은 GPS 좌표 정밀도·출입구·실제 이동 경로 검증을 대신하지 않습니다. 가격·영업시간·공사 상태는 실시간 정보가 아니므로 공식 안내를 확인하세요.

## 앱과 데스크톱

앱은 이 저장소를 읽기 전용으로 사용합니다. 누락 장소 요청은 공개 GitHub 이슈로 올리지 않고 사용자의 PC 중계기에 저장합니다. 로그인된 Codex 데스크톱 대화가 대기 요청을 조사하고 이 저장소의 새 팩을 게시합니다. 별도 Codex CLI 로그인이나 API 키는 사용하지 않습니다.

휴대폰에는 GitHub 쓰기 권한이나 Codex 인증 정보가 들어가지 않습니다. 요청에는 장소명·도시·주소·선택한 장소의 참고 좌표만 포함하며 여행 이름, 메모, 현재 GPS는 포함하지 않습니다. 출처로 장소를 특정할 수 없으면 `needs_info`로 남깁니다.

`build.py`는 빈 출력 카탈로그에서 초기 자료를 만드는 도구입니다. 기존 인덱스가 있으면 실행을 거부하여 갱신된 팩을 초기 버전으로 덮어쓰지 않습니다. 기존 장소를 갱신할 때는 해당 지역 버전을 올리고 인덱스와 팩을 함께 게시해야 합니다. PC 중계기의 운영 파일과 인증 설정은 이 공개 저장소에 포함하지 않습니다.
