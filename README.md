# 여행노트 이야기 가이드

출처를 연결한 한국어 이야기 해설과 지역별 오프라인 팩입니다. 첫 공개본은 12개 지역의 대표 장소 12곳입니다. 세계의 모든 관광지를 수록한 데이터베이스는 아닙니다. 기존 `travel-guide-packs`의 1,731개 설명을 검증된 자료인 것처럼 복제하지 않았습니다.

`index.json`의 실제 UTF-8 바이트 크기와 SHA-256으로 다운로드를 검증합니다. 각 장소는 별칭, 도시, 참고 좌표, 해설, 조사일, 출처를 갖습니다. 참고 좌표는 GPS 안내용 위치 확인을 대신하지 않습니다.

## 자료 사용과 출처

한국어 본문은 Codex가 연결된 Wikipedia의 사실을 바탕으로 새로 구성했습니다. Wikipedia 기여자의 원문은 각 `sources` 링크에서 확인할 수 있습니다. 본문은 CC BY-SA 4.0으로 제공합니다. 사실의 선택·재구성과 한국어 이야기 구성에 변경이 있습니다. 원문 인용, Google 리뷰·사진의 복제는 포함하지 않습니다.

Google 지도 검색 링크는 장소마다 제공하지만, 초기 자료의 `mapsVerification`은 `pending`입니다. 조사 도구의 지도 본문 접근이 제한되어 지도상 장소의 일치까지 검증했다고 표시하지 않았습니다. 가격·영업시간·공사 상태는 실시간 정보가 아니므로 공식 안내를 확인하세요.

## 앱과 데스크톱

앱은 이 저장소를 읽기 전용으로 사용합니다. 누락 장소 요청은 공개 GitHub 이슈로 올리지 않고 사용자의 PC 중계기에 저장합니다. 로그인된 Codex 데스크톱 대화가 대기 요청을 조사하고 이 저장소의 새 팩을 게시합니다. 별도 Codex CLI 로그인이나 API 키는 사용하지 않습니다.

휴대폰에는 GitHub 쓰기 권한이나 Codex 인증 정보가 들어가지 않습니다. 요청에는 장소명·도시·주소·선택한 장소의 참고 좌표만 포함하며 여행 이름, 메모, 현재 GPS는 포함하지 않습니다. 출처로 장소를 특정할 수 없으면 `needs_info`로 남깁니다.

`build.py`는 초기 자료를 재현하는 도구입니다. 운영 중 갱신된 팩을 초기 데이터로 덮어쓰지 마세요. PC 중계기의 운영 파일과 인증 설정은 이 공개 저장소에 포함하지 않습니다.
