# 여행노트 이야기 가이드

출처를 연결한 한국어 이야기 해설과 지역별 오프라인 팩입니다. 현재 31개 국가·권역, 66개 지역의 271개 장소를 수록합니다. 확정한 주요 관광도시 50곳에 각각 대표 명소 5곳씩 250개를 수록했고, 기존 국내 추가 자료 16곳도 보존했습니다. 프라하는 주요 명소 5곳을 추가해 10곳으로 확장했습니다. 참고 저장소의 34개 지역 모두에 최소 한 장소가 있으며 추가 해외 지역은 32개입니다. 아테네 아크로폴리스는 누락 장소 요청 흐름을 통해 새로 조사해 추가했습니다. 방문 계획을 세울 때 인덱스의 실제 수록 목록을 확인해 주세요. 세계의 모든 관광지를 수록한 데이터베이스는 아닙니다.

`index.json`의 실제 UTF-8 바이트 크기와 SHA-256으로 다운로드를 검증합니다. 각 장소는 별칭, 도시, 참고 좌표, 해설, 조사일, 출처를 갖습니다. 참고 좌표는 GPS 안내용 위치 확인을 대신하지 않습니다.

## 자료 사용과 출처

한국어 본문은 Codex가 연결된 Wikipedia의 사실을 바탕으로 새로 구성했습니다. Wikipedia 기여자의 원문은 각 `sources` 링크에서 확인할 수 있습니다. 본문은 CC BY-SA 4.0으로 제공합니다. 사실의 선택·재구성과 한국어 이야기 구성에 변경이 있습니다. 원문 인용, Google 리뷰·사진의 복제는 포함하지 않습니다.

Google 지도 검색 링크를 장소마다 제공합니다. 142곳은 색인된 지도 페이지에서 이름·도시와 표시된 경우 주소를 확인해 `mapsVerification: indexed-identity`로 기록했습니다. 나머지 129곳은 분리된 숨김 브라우저의 실제 지도 화면에서 장소명과 주소 또는 지역을 대조해 `live-identity`로 기록했으며, 확인한 이름·지역은 `mapsIdentity`에 남겼습니다. 반테아이 스레이는 동명 지역 대신 현지어 사원명으로, 시텐노지는 동명 지구 대신 사찰로, 랑이토토는 항로 대신 섬으로 구분했습니다. 테이블 마운틴의 지도 결과는 산 정상인 Maclear's Beacon이며 출입구가 아닙니다. 전체 271곳의 장소 식별을 확인했지만 이 확인은 GPS 좌표 정밀도·출입구·실제 이동 경로 검증을 대신하지 않습니다. 가격·영업시간·공사 상태는 실시간 정보가 아니므로 공식 안내를 확인하세요.

## 앱에서 사용하기

앱은 이 저장소를 읽기 전용으로 사용합니다. 앱 설정의 지역별 여행 가이드에서 목록을 새로고침하고 원하는 지역을 다운로드하세요. 프라하 팩 5판에는 주요 명소 10곳의 해설이 들어 있습니다. 이미 프라하를 내려받았다면 목록 새로고침 후 다시 받기를 사용합니다.

저장한 자료는 인터넷 없이 읽거나 기기의 한국어 음성으로 들을 수 있습니다. 기기에서 팩을 삭제해도 여행 일정과 직접 쓴 해설은 남습니다. v14는 새 해설 신청·PC 연결 기능을 제공하지 않습니다. 휴대폰에 GitHub 쓰기 인증이나 Codex 인증 정보가 들어가지 않습니다.

`build.py`는 빈 출력 카탈로그에서 초기 자료를 만드는 도구입니다. 기존 인덱스가 있으면 실행을 거부하여 갱신된 팩을 초기 버전으로 덮어쓰지 않습니다. 자료를 추가할 때는 기존 장소를 보존하고 해당 지역 버전을 올린 뒤 인덱스와 팩을 함께 게시해야 합니다.
